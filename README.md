# 伴语星球

把情绪变成可见的符号，把成长写进只属于自己的加密日记，并在需要时把性情和状态只交给你想让看见的人。

## 本地运行

需要 Node.js 22。

```bash
nvm use
npm install
npm run dev
```

打开 [http://localhost:3000](http://localhost:3000)。

日记和完整情绪记录只加密保存在浏览器本地，不会上传。分享链接只包含用户授权的性情与状态。

## 脚本

```bash
npm run dev    # 开发
npm run build  # 生产构建
npm test       # 单元测试
```
