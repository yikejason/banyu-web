# 伴语星球 Web MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在网页端交付伴语星球 MVP：情绪视觉化、本地加密日记、定向私密分享，并用 Vercel 部署。

**Architecture:** 纯前端为主的 Next.js App Router 应用。日记与完整情绪记录只存在浏览器 IndexedDB，经 Web Crypto AES-GCM 加密，任何 Route Handler 都不得接收日记明文。分享快照（性情 + 状态 + 视觉符号）在客户端加密后，只把密文存到服务端以便跨设备打开和撤回；解密密钥放在 URL hash 中，服务端无法还原明文。UI 按 [Material Design 3](https://m3.material.io/) 的颜色、字体、形状、动效规范，用 Tailwind CSS 实现组件，不引入已停更的 Material Web Components。

**Tech Stack:** Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS v4 · [Material Design 3](https://m3.material.io/) tokens · `@material/material-color-utilities` · Web Crypto · IndexedDB (`idb`) · Vitest · Testing Library · Playwright · Vercel

**Spec:** [`产品文档.md`](../../产品文档.md)

## Global Constraints

- 平台：只做 Web，不做原生 App / 小程序。
- 日记正文、附件、完整情绪原始记录：**100% 本地加密，不云端保存，不做云同步。**
- 分享默认不含日记原文，只含用户勾选的性情与状态。
- 分享必须由用户主动生成链接并亲自发送；产品不广播、不推荐、无广场。
- 用户可随时让分享链接失效。
- 情绪映射不做心理诊断，允许「说不清 / 混杂 / 说不出口」。
- UI 必须使用 M3 token（`primary` / `on-primary` / `surface` / `outline` 等），禁止随意写死 Tailwind 调色板颜色作为主色。
- 文案克制、不评判、不鸡汤；中文界面。
- 本期不做：公开动态、关注评论点赞、云同步、陌生人匹配、心理咨询。

## 技术选型说明

| 项 | 选择 | 原因 |
| --- | --- | --- |
| 框架 | Next.js 16 App Router | 用户指定；便于 Vercel 部署与分享落地页 |
| 样式 | Tailwind CSS v4 | 用户指定；用 `@theme` 接入 M3 token |
| UI 规范 | [Material Design 3](https://m3.material.io/) | 用户指定。官方 [Material Web](https://m3.material.io/develop/web) 处于 maintenance mode，不采用 |
| 颜色算法 | `@material/material-color-utilities` | Google 官方 M3 动态配色 |
| 组件 | 自研 `src/components/m3/*` | 用 Tailwind 实现 M3 Button / FAB / TextField / Card / Dialog / NavigationBar 等，避免伪 Material 库 |
| 本地存储 | IndexedDB + AES-GCM | 满足「日记不上云」 |
| 分享中继 | `app/api/shares` 只存密文 + 撤回标记 | 满足跨设备打开与可撤回；服务端无密钥 |
| 部署 | Vercel | 用户指定 |

**分享与微信：** 解密密钥放在 URL hash（`/s/{id}#k=...`），不会随 HTTP 请求发给 Vercel。部分 App 内置浏览器会丢掉 hash，计划在分享页提供「口令查看」兜底（口令由分享者当面告知，服务端只存口令哈希，不是 AES 密钥）。

- [ ] **Step 3: 实现 bytes / key / aes**

```ts
export async function deriveKey(
  passphrase: string,
  salt: Uint8Array,
  iterations = 310_000,
): Promise<CryptoKey> {
  const material = await crypto.subtle.importKey(
    "raw",
    new TextEncoder().encode(passphrase),
    "PBKDF2",
    false,
    ["deriveKey"],
  );
  return crypto.subtle.deriveKey(
    { name: "PBKDF2", salt, iterations, hash: "SHA-256" },
    material,
    { name: "AES-GCM", length: 256 },
    false,
    ["encrypt", "decrypt"],
  );
}
```

`encryptUtf8` 使用 12 字节随机 IV。

## 数据流（实现时不得打破）

```text
用户口令 ──PBKDF2──► 内存中的 VaultKey ──AES-GCM──► IndexedDB(records)
                                              ▲
                                              └── 日记 / 完整情绪 / 性情 / 本地分享元数据

分享：Snapshot(性情+状态) ──随机 ContentKey AES-GCM──► POST /api/shares（仅密文）
      ContentKey ──► URL hash #k=
      RevokeToken ──► 本地 shareLocal 记录
被分享者：GET 密文 + hash 密钥 ──解密──► 只读星球（无日记）
撤回：DELETE + x-revoke-token ──► 密文不可再取
```

## 明确不做（防止计划膨胀）

- 账号系统 / OAuth / 云备份
- 多设备同步
- AI 情绪分析（可用后期可选模型，不得作为日记出站通道）
- PWA 离线作为本期硬性范围（IndexedDB 已能刷新后保留；可后续加）
- 原生分享 SDK、通讯录读取
